# 🛡️ SafeNana Backend

REST API powering **SafeNana** — a two‑interface elderly safety platform built after my grandmother nearly lost her savings to a phone scammer.

---

## 📌 What It Does

Handles all backend logic for SafeNana:

- Daily check‑in signals from elderly users  
- Real‑time family dashboard data  
- Scam alert notifications  
- User authentication  

---

## ⚙️ Tech Stack

- **Node.js**  
- **Express.js**  
- **MongoDB**  
---

## 🎨 Frontend

Explore the frontend repository and live demo:

## 🔑 Environment Variables

Create a `.env` file with:

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```
